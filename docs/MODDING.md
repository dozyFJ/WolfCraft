# Как сделать технический мод в «Кубикс»

Мод — это набор блоков, предметов и рецептов плюс логика. Сейчас всё добавляется кодом в движок
(`wolfcraft-engine`, `wolfcraft-assets`). Готовый пример — «Техника» (электросеть).

## 1. Блок
1. **Текстура** — `wolfcraft-assets/src/procedural/blocks.rs`: константа в `tiles` и `l.add(ID, "имя", p(|q| ...))`.
   Порядок `l.add` должен совпадать с номерами.
2. **Реестр** — `wolfcraft-engine/src/block.rs`, в `blocks!` добавь строку с **следующим** id
   (id хранятся в сейвах, порядок не менять). Модификаторы: `needs_pick`, `emissive`, `ore`.
3. **Дроп** — `items.rs::drops` (по умолчанию блок выпадает сам).
4. **Вкладка** в инвентаре — `items.rs::category`.

## 2. Предмет
Спрайт в `items_paint.rs` (`items::*`), id в `items.rs::ids` (+ `LAST`), имя в `items::info`.

## 3. Рецепт
`inventory.rs::recipes()` — `r(&[(предмет, кол-во)], (результат, кол-во), нужен_верстак, "Категория")`.

## 4. Генерация руд
`planet.rs::ore_at` — новая ветка `else if roll < N && глубина > M`.

## 5. Логика (редстоун / электричество)
`wolfcraft-engine/src/power.rs`: событийная сеть. После установки или слома блока
`session.rs` вызывает `power::update_around(&mut chunks, клетка)`.

| Блок | Роль |
|---|---|
| Генератор | источник питания (всегда включён) |
| Медный кабель, Аккумулятор | проводят питание между соседними блоками |
| Электролампа | потребитель: горит (`ElectricLampOn`), если касается запитанной сети |

Новый потребитель: добавь пару блоков «выкл/вкл» и обработай их в `power.rs`
(`is_lamp` → своя функция).

## Цепочка крафта примера
сырая медь/олово + уголь → слитки → 3 меди + 1 олово → 4 бронзы;
железо + олово → корпус машины → генератор / аккумулятор / электропечь;
кабель + генератор + электролампа = работающая цепь.
