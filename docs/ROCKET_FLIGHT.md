# Космический полёт

Ракета теперь имеет отдельную объёмную модель с корпусом, четырьмя
стабилизаторами, опорами, соплом и открытой обзорной кабиной. Пилот виден в кабине;
на время полёта включается внешняя камера сзади/сбоку. Выбранный пользователем
режим камеры не меняется, поэтому после посадки обычный вид возвращается.

Этапы: взлёт → орбита и выбор назначения → 4-секундный разгон → загрузка
планеты назначения и торможение → высадка на поверхность. Это постановочный
переход между мирами, а не единая физическая солнечная система. При загрузке
земли ракета ждёт готовности чанков. Сенсорные кнопки перемещения, хотбар и
руки первого лица скрываются; E/F5 не прерывают внешнюю камеру.

Вид из космоса получает ступенчатый объёмный рельеф из высот настоящего
генератора, с боковыми гранями уступов. Это дальняя модель низкой детализации,
не загрузка всей планеты блок за блоком. Возле игрока уже использовались и
продолжают использоваться полноценные редактируемые воксельные чанки.
Дальняя модель пока не отражает пользовательские изменения поверхности.
Соседние миры в небе тоже имеют объёмные ступенчатые грани; это декоративные
дальние модели Луны, Игниса, Глации и Ксеноса, не редактируемые чанки.

Ограничения: перелёты в мультиплеере по-прежнему отключены; сохранение фазы
полёта после перезапуска и изоляция состояния механизмов по планетам остаются
отдельными задачами из PLANET_REVIEW. Это изменение их не решает.

Проверки: камера и кадрирование на шести гранях; объём модели и сопло;
геометрия рельефа и границы неба; переход Home → Moon, сохранение точки старта,
посадка и восстановление режима полёта/камеры. Тест перелёта запускается отдельно
из-за глобального масштаба гравитации. На физическом Android-устройстве не проверено.
