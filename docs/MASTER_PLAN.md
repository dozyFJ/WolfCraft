# WolfCraft — план большого обновления

Статус по разделам ТЗ «Master Update & Redesign». Честно разделено: **готово** (есть в коде),
**частично**, **запланировано** (кода ещё нет).

Проект: 6 крейтов (`common`, `assets`, `engine`, `ui`, `game`, `launcher`), ~17,6 тыс. строк Rust,
wgpu 22 + winit 0.30 + egui 0.29. Windows и Android собираются из одной кодовой базы.

## Важное расхождение с ТЗ
ТЗ (п. 5) просит «не вводить сферическую геометрию». В WolfCraft она **уже есть и работает**:
планета-кубосфера (`cubesphere.rs`), гравитация к центру, чанки по граням куба, плавающее начало
координат. Убирать её — значит переписать движок и потерять все сохранения. Оставлено как есть.

## 8. WolfForge (моды)
Сейчас моды добавляются кодом в движок (`docs/MODDING.md`). Скриптовый язык — Luau (как в
Роблоксе): скрипт мира из студии с API игрока, мира, событий, таймеров и GUI (ScreenGui-подобные
кнопки, надписи, панели). Rhai не используется. Запланировано: реестр блоков/предметов из
данных (TOML) и моды на Luau. Версия API объявлена: `MOD_API_VERSION` в
`wolfcraft-common/src/version.rs`.
