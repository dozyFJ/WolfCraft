# Энергосеть WolfTech

Энергия рассчитывается отдельной системой: **20 тактов в секунду**, один такт — 0,05 с. Рендер передаёт реальное прошедшее время без сглаживания и ограничения физического кадра. Остаток времени сохраняется; при задержке кадра такты догоняются порциями. Замедление катсцены не замедляет энергию. В одиночной игре пауза останавливает симуляцию; открытое окно машины её не останавливает.

Источники предлагают мощность в ЭЕ/с, устройства хранят ЭЕ в буферах. Сначала сеть пропорционально покрывает запросы работающих машин, затем запасает избыток в ячейках и буферах. Пустующие машины не отбирают питание для предварительного заполнения. Кабели образуют связные компоненты по соседним клеткам, включая грани планеты. Общего ограничения обхода 4096 клеток нет. Топология обновляется при изменениях и периодически; источники используют окружающие воду, лаву, высоту, освещение и погоду.

Все генераторы — обычный, солнечный, ветер, геотермальный, водяной и реактор — используют эту модель. Зарядка переносит дробный остаток; быстрые машины могут завершать несколько операций за такт и сохраняют остаток работы. Энергомеч разряжается, но не исчезает; разряженная нано-броня не даёт энергетическую защиту. Окна показывают фактическую генерацию/расход последнего такта.

## Сетевая игра

Протокол **4**: обновить нужно и игру, и сервер. APK-оболочка не меняется, совместимый OTA-загрузчик получает исправления без нового APK.

Сервер рассчитывает машины даже без подключённых игроков. Клиенты получают общие слоты, энергию и прогресс. Перенос предметов проверяет сохранение количества и метаданных, правила слотов и актуальность изменяемых слотов. Одновременное изъятие одного предмета получает только один клиент.

Операция сначала записывается в локальный журнал. Сервер атомарно сохраняет состояние вместе с квитанцией, затем подтверждает перенос. После обрыва клиент запрашивает ту же квитанцию; неизвестная операция отменяется так, чтобы запоздавший пакет не мог применить её позже. До разрешения переноса инвентарь заблокирован. Квитанция привязана к конкретному миру; другой мир на том же адресе не откатывает чужую операцию.

Это не новая система античита: владение обычным инвентарём игрока сохраняет существующую модель доверия к клиенту. Защищены согласованность общего состояния машин и штатные повторы/обрывы операций.

Заполненную сетевую машину перед разборкой требуется опустошить. Предметы сначала переносятся в инвентарь, затем их можно выбрасывать. При потере сервера клиент возвращается в меню, а не продолжает отдельную локальную фабрику.

## Сохранение

Обычное одиночное сохранение записывает энергию, прогресс, горение и дробную зарядку в `tech.txt` / `tech_hell.txt`. Сервер использует `wolftech-server.json` с резервной копией; состояние и квитанции записываются вместе. При завершении сервера состояние экспортируется для одиночного режима, сохраняя посторонние сундуки. Следующий запуск сервера подхватывает изменения одиночного мира.

## Проверки

Регрессии проверяют такты при 1–240 FPS, зарядку, справедливость питания, большие независимые сети, ускоренные машины, новые источники, заряд снаряжения, обычное сохранение мира, передачу состояния между режимами, двух TCP-клиентов у одной машины, повторные операции, восстановление квитанций и ошибку записи на диск. Полный цикл двух Android-телефонов дополнительно проверяется на устройствах.
