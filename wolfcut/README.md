# WolfCut

Настольный видеоредактор на Rust 2024, egui 0.29, wgpu 22 и winit 0.30. Eframe связывает интерфейс и оконную систему. FFmpeg и FFprobe обрабатывают медиа.

## Запуск

Установите Rust и добавьте `ffmpeg` и `ffprobe` в PATH. Для экспорта нужна сборка FFmpeg с кодировщиками libx264 и AAC. На Linux диалоги файлов используют XDG Desktop Portal или Zenity.

```sh
cargo run --release
```

Добавьте видео через диалог или перетащите файлы в окно. Выберите клип на монтажной дорожке, задайте начало и конец и перемещайте курсор для просмотра кадров. Кнопки «Раньше» и «Позже» меняют порядок клипов. «Экспорт MP4» объединяет их в один файл H.264/AAC, 1280 × 720, 30 кадров в секунду.

Текущая версия поддерживает покадровый предпросмотр по ползунку и одну последовательность клипов. Монтажная сессия хранится в памяти до закрытия приложения.

## Android

Android-версия использует тот же редактор и системные диалоги выбора и сохранения файлов. Поддерживаются устройства ARM64 с Android 8.0 и выше. Экспорт сохраняет MP4 720p с видео MPEG-4 и звуком AAC.

Для сборки на Linux нужны Rust с целью `aarch64-linux-android`, JDK, Android SDK 35, Build Tools 35.0.0, NDK r27d, исходники [FFmpeg 7.1.5](https://ffmpeg.org/releases/ffmpeg-7.1.5.tar.xz), `make` и `zip`.

```sh
rustup target add aarch64-linux-android
./android/build-ffmpeg.sh /path/to/ffmpeg-7.1.5 /path/to/ndk /path/to/ffmpeg-output
./android/build-apk.sh /path/to/android.jar /path/to/build-tools /path/to/ndk \
  /path/to/ffmpeg-output /path/to/keystore /path/to/WolfCut.apk
```

Перед сборкой задайте `WOLFCUT_KS_PASS` и, если имя ключа отличается от `androiddebugkey`, `WOLFCUT_KS_ALIAS`.

### OTA

Android-клиент проверяет `android/update.json` в ветке `wolfcut` при запуске. Кнопка «Обновления» также запускает проверку вручную. При появлении новой версии кнопка «Обновить» скачивает APK и передаёт его системному установщику после проверки SHA‑256, имени пакета, версии и подписи.

При выпуске увеличьте `versionCode`, подпишите APK тем же ключом и разместите `WolfCut-arm64.apk` в корне тега `wolfcut-v<versionName>`. После проверки скачивания обновите `android/update.json` с соответствующей версией и SHA‑256.

Интерфейс Android открывается в портретной ориентации. На узком экране обрезка и дорожка монтажа расположены под предпросмотром.


### Дорожки монтажа

Таймлайн под предпросмотром содержит дорожки «Видео», «Текст» и «Аудио». Кнопки слева добавляют материалы. На настольной версии можно также перетащить медиафайл на таймлайн. Перетаскивайте блоки, чтобы переставить видео или изменить время начала текста и аудио. Выберите блок и нажмите «Править», чтобы обрезать видео, изменить титр или удалить элемент.

Титры видны на предпросмотре. При экспорте они накладываются на изображение, а добавленные аудиофайлы смешиваются с исходным звуком видео.
